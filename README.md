# ЭХО

Браузерная 3D-стелс игра: робот ЭХО-01 собирает энергоячейки в лабиринте и прячется от невидимых Охотников, которые слышат каждый звук.

**Играть:** https://daniilstrekalev0201.github.io/echo-game/

Управление на компьютере: WASD — идти, Shift — бег, C — присесть, ЛКМ/Пробел — сонар, ПКМ/F — приманка, Q/E — повернуть камеру, Esc — пауза.

На телефоне: коснись экрана и тяни — джойстик (до края — бег), карточки «Сонар», «Приманка» (тяни в точку броска) и «Присесть», кнопки ⟲ ⟳ поворачивают камеру.

Подробности механики — в [DESIGN.md](DESIGN.md).
